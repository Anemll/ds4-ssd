The development of efficient inference engines for large language models requires careful attention to memory bandwidth, compute utilization, and the interplay between the CPU, GPU, and neural accelerators. In a mixture-of-experts transformer, each token is routed to a small subset of experts, while a shared expert processes every token. During the prefill phase, all prompt tokens pass through each layer together, which turns the per-token projections into large batched matrix multiplications. The goal of this test is to exercise that batched path end to end and verify numerical correctness.
