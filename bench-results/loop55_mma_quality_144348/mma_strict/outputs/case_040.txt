1.  **Time-Per-Token (TPT) vs. Context Window Position**  
    Measure the latency per generated token as a function of the position in the context window (e.g., token 1 vs. token 8k vs. token 32k). This isolates whether the slowdown is due to the *generation* phase itself or the *pre-fill/attention* phase.
