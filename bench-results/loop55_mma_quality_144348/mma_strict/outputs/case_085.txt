A compiler uses an abstract syntax tree (AST) as an intermediate representation of the source code's grammatical structure, where each node represents a construct (like a statement, expression, or variable) and edges represent relationships between them, stripping away syntactic details like parentheses or semicolons. After the parser generates the AST from the token stream, the compiler traverses this tree to perform semantic analysis (e.g., type checking, symbol resolution) and then uses it to generate lower-level representations like intermediate code or machine code, often applying optimizations by analyzing or transforming the tree's structure.
