A compiler uses an abstract syntax tree (AST) as an intermediate representation of the source code after parsing, where the tree structure captures the program's logical structure and semantic relationships without syntactic details like parentheses or semicolons. During semantic analysis, the compiler traverses the AST to perform type checking, resolve variable references, and enforce language rules, then uses the annotated tree to generate intermediate code (e.g., three-address code) or directly produce machine code by recursively visiting nodes and emitting corresponding instructions, optimizing the tree's structure for efficient translation.
