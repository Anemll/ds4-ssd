Here's a short C function that clamps an integer to a specified range:

```c
int clamp(int value, int min, int max) {
    if (value < min) return min;
    if (value > max) return max;
    return value;
}
```

This function:
- Takes an integer value and a range [min, max] (inclusive)
- Returns `value` if it's within the range
- Returns `min` if the value is below the minimum
- Returns `max` if the value is above the maximum
