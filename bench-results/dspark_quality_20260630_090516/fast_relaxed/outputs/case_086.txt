A checksum catches accidental corruption by exploiting the fact that even a small change in the data—such as a single bit flip during transmission—will almost certainly produce a different checksum when the data is re-hashed. The checksum is a fixed-size value derived from the original data using a deterministic algorithm (like CRC or a hash). When the receiver recalculates the checksum from the received data and compares it to the original checksum, any mismatch indicates that the data has been altered, because the algorithm is designed so that different data inputs produce different checksums with very high probability.
